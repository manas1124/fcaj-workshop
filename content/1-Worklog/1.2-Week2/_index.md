### Activities

This week focused on AWS storage and database services.

I started by studying Amazon S3, including Buckets, Objects, Storage Classes and Lifecycle Policies for cost optimization. I then explored Amazon EBS to understand how block storage is attached to EC2 instances and practiced creating snapshots for backup and recovery.

Next, I learned how Amazon RDS simplifies relational database deployment and management, including instance creation and connectivity.

Finally, I completed a hands-on exercise by building a simple file upload system that stores uploaded files in Amazon S3 and verified its functionality through testing.
