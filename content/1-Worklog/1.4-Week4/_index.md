### Activities

This week focused on AWS identity management and security. I studied AWS Identity and Access Management (IAM), including Users, Groups, Roles and Policies, and practiced applying the Principle of Least Privilege to control access to AWS resources.

I also configured Multi-Factor Authentication (MFA) and explored how IAM Roles provide temporary credentials for AWS services without exposing long-term access keys.

To prepare for the upcoming project phase, I learned the fundamentals of AWS Lambda and Amazon API Gateway by building a simple serverless API. This exercise helped me understand the Function as a Service (FaaS) execution model and the request flow between API Gateway and Lambda.

At the end of the week, I reviewed the AWS services learned during the first month and created the initial development plan for the Smart Campus Platform project.
