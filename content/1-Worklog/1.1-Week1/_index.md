### Activities

During the first week, I focused on becoming familiar with AWS and the AWS First Cloud Journey learning program. I studied the fundamental concepts of Cloud Computing and explored the main AWS service categories, including Compute, Storage, Networking, Database and Security.

I then created an AWS account and configured AWS Budgets together with Billing Alarms to monitor cloud spending during hands-on practice. This helped establish good cost management habits from the beginning.

For the practical session, I learned the basics of Amazon EC2, including AMIs, Instance Types, Key Pairs and Security Groups. I successfully launched an EC2 instance, connected to it via SSH, installed Apache Web Server and verified that the web application was accessible through the instance's public IP address.

---

### Challenges

* Becoming familiar with the AWS Management Console due to the large number of available services.
* Understanding the differences between AMIs, EC2 instances and EBS volumes.
* Incorrect Security Group configuration initially prevented external access to the web server.
* Learning how SSH authentication works using Key Pairs.

---

### Solutions

* Studied the official AWS documentation together with the AWS First Cloud Journey learning materials.
* Reconfigured Security Groups and verified Apache service status.
* Practiced creating and configuring multiple EC2 instances to better understand the deployment workflow.
* Recorded the deployment process for future reference.
