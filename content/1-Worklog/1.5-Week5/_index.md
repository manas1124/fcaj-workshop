### Activities

This week marked the transition from AWS learning to project development.

I selected **Smart Campus Platform** as the final project and analyzed the business requirements to define the Minimum Viable Product (MVP). The project focuses on building a serverless attendance management system using AWS cloud services.

I designed the overall architecture based on the AWS Well-Architected Framework, adopting a serverless and event-driven architecture. The system includes Amazon API Gateway, AWS Lambda, Amazon Cognito, Amazon S3, Amazon DynamoDB, Amazon EventBridge, Amazon SNS, Amazon SES and Amazon CloudWatch.

I also designed the major workflows, including face registration, attendance processing, notifications, analytics and AI integration. Finally, I completed the repository structure and created a milestone-based implementation plan for the following development phase.

### Challenges

* Defining a realistic project scope.
* Balancing project complexity with the available development time.
* Selecting the most appropriate AWS services for each component.
* Designing a scalable architecture while keeping the MVP manageable.

### Solutions

* Reduced the project scope to focus on the face attendance module.
* Divided the project into multiple development milestones.
* Studied the AWS Well-Architected Framework and official AWS documentation.
* Designed a modular architecture for future scalability.
